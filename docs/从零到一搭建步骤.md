# 从零到一搭建步骤（详细版）

**简体中文** ｜ [English](setup-from-zero.en.md)

> README 第三节的扩写。每一步都给「做什么 + 为什么 + 验收标准」。

## 步骤 1 · 建目录骨架
```
my-knowledge-base/
├── AGENTS.md
├── raw/  wiki/  modules/  outputs/  references/
```
**为什么**：先有骨架，后面所有资料才有落点。
**验收**：五个目录 + 一份 AGENTS.md 就位。

## 步骤 2 · 写 AGENTS.md（最关键）
用 [`templates/AGENTS.example.md`](../templates/AGENTS.example.md)，填入：
- 你是谁、沟通偏好；
- 红线（隐私黑名单、复用不改原版、减法先过目、时间快照不清理、只写上下文有的）；
- 知识库在哪、怎么查（检索命令）。
**为什么**：这是 AI 接手时的唯一上下文，写不清 = AI 瞎猜。
**验收**：换一个 AI 工具读它，能正确说出你的红线与知识库位置。

## 步骤 3 · 定沉淀规则（三问过滤器）
资料进来先过：**会再用？库里没有？能追溯？** 三问全否不收。
**落点三处**：`raw/` + `wiki/` + 准则（是规矩就升版本号）。
**验收**：一周后抽查，收到的资料都有去处、无「说要沉淀却没沉淀」。

## 步骤 4 · 装索引链路（进阶，但值得早建）

把 `wiki/` 建索引，AI 用检索代替凭记忆。这是「第二条链路」，完整设计见 [`双链路体系.md`](双链路体系.md)，
最小可运行实现见 [`examples/mini_index.py`](examples/mini_index.py)（约 160 行，纯标准库）。

**验收**：问一个库内问题，AI 回答能附出来源路径；库里没有的明确说没有。
改完 md 跑一次 `build`，连续两次第二次应全「未变」。

## 步骤 5 · 建第一个能力模块
在 `modules/` 下建目录 + 脚本 + README（用法 / 调用链路 / 坑）。
**验收**：别人照 README 能跑起来。

## 步骤 6 · 开技能工作台
把常用提示词封成卡片。详见 [`技能工作台.md`](技能工作台.md)。
**验收**：常用话术一键复制，不用来回翻聊天记录。

## 步骤 7 · 装知识库体系门户
把 `kb-hub/` 放进根目录，双击 `start-kbhub.bat`。
**验收**：浏览器打开 8799 端口，能看到全部系统/技能/项目，点「记一次」后「每日常用」出现条目。

## 收尾
- 每次任务结束过 [`../README.md`](../README.md) 的收工检查；
- 持续把「规矩」升版本号，把「知识」写进 wiki。
