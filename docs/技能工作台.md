# 技能工作台：把提示词与技能固化成卡片

**简体中文** ｜ [English](skill-workbench.en.md)

> 对应 README 第五节。核心回答：「我的提示词、AI 的思考提示词，有没有做成卡片？」
>
> 路径说明：中文版用 `modules/技能工作台/`、`wiki/提示词资产/`；英文版为可读性写成 `modules/skill-workbench/`、`wiki/prompt-assets/`。
> 目录名随你自己定，关键是扫描器与模板保持一致。

## 一、机制已经存在

技能工作台（`modules/技能工作台/`）把分散在各处的技能/模块/提示词统一成**卡片**，当前可管理 100+ 张，按来源分 6 类：

| 来源分类 | 是什么 |
|---|---|
| 提示词资产 | **作者立规类提示词 + AI 工作模式卡片**（复用副本不改原版、上传先问、版本三件套、去水印、决策解释义务、先查轮子等） |
| 用户级 / 项目级 | 你装的 Skill、项目专属技能 |
| 知识库模块 | `modules/` 下每个能力模块一张卡（点名模块 + 用途 + 参考命令 + 模块位置） |
| 内置 / 插件 | AI 工具自带与插件市场的技能 |

每张卡带四件套：**即用话术（`{动态参数}` 占位）+ 落地例子 + 例子中英对照 + 触发词**。支持搜索、收藏、置顶、一键复制（参数自动填空）、话术编辑、隐藏/恢复、新增、导出导入备份。

## 二、提示词是怎么变卡片的

**不是每次对话自动封存**，而是「对话提示词封存成卡片」的**标准动作**：
1. 某次对话里沉淀出一条值得复用的规矩或话术；
2. 写成 `wiki/提示词资产/<主题>.md`；
3. 重跑 `scan_skills.py` 刷新，卡片自动进工作台。

所以——**你立下的规矩、AI 的工作模式，都已经是卡片**；临时对话里的零散提示词，需要走上面三步才会进卡片库。这正是「只加不减、沉淀挂靠在事上」的体现。

## 三、和知识库体系门户的关系

门户的「技能卡片」页直接复用工作台的扫描产物（`skills_data.json`），点「打开技能工作台」即可跳过去复制话术；门户的「记一次」可给某张卡加热度，让高频卡在「每日常用」里优先出现。

## 四、怎么新增一张自己的卡

1. 在 `wiki/提示词资产/` 新建 `<主题>.md`，写清：适用场景、话术（带 `{参数}` 占位）、例子；
2. 运行 `modules/技能工作台/scan_skills.py`；
3. 打开 `modules/技能工作台/index.html`，搜得到即成功。
