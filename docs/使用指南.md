# 使用指南：别人怎么用这个项目

**简体中文** ｜ [English](usage.en.md)

> 你已经下载或克隆了本仓库。这篇文档专讲「拿到之后怎么真正用起来」，不重复 README 的理念与从零搭建步骤。
> 如果还没读 README，请先看 [README.md](README.md)（它讲「这是什么、为什么这样设计」）。

## 一、这个仓库给你什么

| 你拿到的是 | 干什么用 | 在哪 |
|---|---|---|
| **知识库体系门户（KB Hub）** | 一个本地网页仪表盘，把你的系统 / 技能 / 项目 / 资源 / 工具聚到一屏，按每日热度排序 | `kb-hub/` |
| **空白模板** | 一套「可直接复制去用」的知识库骨架（AGENTS.md / wiki / modules / 提示词） | `templates/` |
| **方法论文档** | 架构、双链路、检索层设计与评测、开源守则、FAQ | `docs/` |
| **守则执行工具** | 示例清单生成器、隐私扫描器、双语校验器 | `tools/` |
| **安装说明** | 从 Releases 下载 exe / zip 怎么装 | [RELEASE.md](RELEASE.md) |

> ⚠️ **本开源仓库不含 RAG 检索引擎本体（`kb_rag.py`）**。它只公开「检索层怎么设计、怎么评测」的方法论（[`docs/检索层设计与评测.md`](检索层设计与评测.md)）。
> 门户里的「🔍 全库检索」页签需要一个**外部的** `kb_rag.py` 才能跑（见第三节）。不配也能用，只是那一页签会提示「未配置检索」。

## 二、两条上手路线（选一条）

### 路线 A：用 exe（零安装，只想用门户）
适合：只想把零散系统聚到一个仪表盘、不想装 Python 环境的人。

1. 到 [Releases](../../releases) 下载 `kb-hub.exe`；
2. 把它放进**你自己的知识库根目录**（和 `raw/ wiki/ modules/` 同级）；
3. 双击 `kb-hub.exe` → 自动开浏览器 `http://127.0.0.1:8799/`；
4. 首次会看到**示例清单**（页面顶部黄色提示条）——正常，它还没扫过你的库；
5. 想看真实数据，做一次「扫描」（见第四节）。

### 路线 B：用源码（想改、想看全部、想跑工具）
适合：想基于模板搭自己的库，或想研究实现的人。

```bash
# 1) 获取源码
git clone https://github.com/DongHangZhao/knowledge-base-from-zero.git
#   或到 Releases 下载 kb-from-zero.zip 解压

# 2) 确认 Python（门户仅用标准库，无需 pip install）
python --version        # 需要 3.10+

# 3) 启动门户
cd kb-from-zero
python kb-hub/kb_hub_server.py --kb-root "你的知识库路径" --port 8799
#   Windows 也可直接双击 kb-hub/start-kbhub.bat
```

浏览器打开 `http://127.0.0.1:8799/` 即可。

### 「🔍 全库检索」怎么用（可选）
这个页签调用知识库侧的 `kb_rag.py`。开源仓库没有它，你需要自己提供：

- **方式一（推荐，本机）**：在 `kb-hub/` 目录放一个 `rag.json`：
  ```json
  {"python": "<装有 jieba/numpy/torch 的解释器路径>", "script": "<你的 kb_rag.py 路径>"}
  ```
- **方式二**：设环境变量 `KB_RAG_PYTHON` / `KB_RAG_SCRIPT`。

未配置时，这一页签会返回明确提示，其余页签照常可用。检索命中可「问知识库」组装带引用的上下文包，直接喂给 AI。

## 四、让门户显示「你自己的库」（关键一步）

门户靠 `inventory.json` 知道你有哪些系统 / 技能 / 项目。没有它就用仓库自带的虚构示例。生成你自己的：

```bash
python kb-hub/inventory_builder.py --kb-root "你的知识库路径"
```

- 产物：`inventory.json`（机器读）+ `知识库体系梳理报告.md`（人类读，等于一份家底盘点）；
- 把 `inventory.json` 放在 `kb-hub/` 旁边（或 exe 同级），**重启门户**即生效；
- 这两个文件含你本机绝对路径和真实模块名，已被 `.gitignore` 排除，**不要提交、不要外传**。

> 以后每次往库里加了模块 / 项目，重跑一次上面的命令，门户就更新了。

## 五、日常使用循环

```
往库里丢资料 / 加模块
        │
        ▼
python kb-hub/inventory_builder.py --kb-root <库>   ← 刷新仪表盘数据
        │
        ▼
双击 kb-hub.exe（或 python kb_hub_server.py）        ← 开门户
        │
        ▼
在「每日常用 / 系统模块 / 资源」里点开即用；
要找资料用「🔍 全库检索」（需配引擎）
```

把门户当「知识库的主屏幕」：今天要干啥，从「🔥 每日常用」进；要找东西，从「🚪 入口 / 资源 / 文件」进。

## 六、让 AI 真正接手你的知识（核心卖点）

本体系的精髓是 **AGENTS.md = 唯一真相源**。把它丢给任意 AI 工具（Codex / Claude Code / Qoder / Trae / Cursor），AI 立刻懂你的：

- 目录架构（`raw` 原件 / `wiki` 合成 / `modules` 能力 / `outputs` 产物，四区不混）；
- 铁律（复用 = 复制副本不改原版、上传先问、减法分级审批、去水印、决策解释义务…）；
- 红线（隐私不上云、开源不可商用须署名…）。

做法：在 AI 工具的会话里 `@` 或粘贴 `AGENTS.md` 全文（配合 `wiki/编码指南/`）。AI 接手即懂，不用每次重讲背景。

## 七、从「我的库」到「你的库」（自定义）

想搭一套自己的体系：

1. 复制 `templates/` 整个目录，改名成你的知识库根；
2. 按里面的空白 `AGENTS.md` / `wiki/README.md` / `modules/示例模块/README.md` 填你自己的内容；
3. 把资料按 `raw/`（原件，只读）和 `wiki/`（合成笔记）分好类丢进去；
4. 跑 `inventory_builder.py` → 开门户 → 用起来；
5. 想加能力，就在 `modules/` 下新建模块目录 + `README.md`，门户会自动收进「系统模块」。

> 模板里所有内容都是占位 / 示例，不含任何作者隐私。

## 八、工具箱（tools/）

| 工具 | 用途 |
|---|---|
| `kb-hub/inventory_builder.py` | 扫描知识库 → 真实清单 + 梳理报告 |
| `tools/privacy_scan.py` | 开源 / 对外前扫一遍，确认没泄露真实姓名 / 学号 / 公司 / 项目名 |
| `tools/` 下的双语校验器 | 查每篇文档的中英两版是否一一对应、有没有漏翻 |

## 九、常见问题

见 [FAQ.md](FAQ.md) / [faq.en.md](faq.en.md)。最高频两条：

- **门户打不开 / 提示示例清单**：没生成 `inventory.json`，跑一次第四节的命令即可。
- **「🔍 全库检索」说未配置**：开源仓库不含引擎，按第三节配 `rag.json` 或用你自己的 `kb_rag.py`。
