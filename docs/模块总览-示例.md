## 检索层（进阶，但值得早建）

**问题**：`wiki/` 几百篇后，AI 凭记忆写路径会出错，且回答无出处。
**方案**：建索引（SQLite FTS5 + 中文分词），AI 用检索代替记忆。

最小可用形态（伪代码）：
```python
# 建索引：扫 wiki/*.md -> 分块 -> 入库
# 检索：query -> 分词 -> FTS5 匹配 -> 返回 top-k 块（带路径）
# AI 作答：把 top-k 块作为上下文，每句标注来源路径
```

**验收**：问一个库内问题，AI 回答能附出来源路径；库里没有的明确说没有。

> 这就是「双链路」的第二条：文件链路之外再加索引链路。
> 表结构、RRF 融合、七个坑、可运行代码 → [`双链路体系.md`](双链路体系.md)。

## 两条红线（模块区）

1. **复用 = 复制副本，绝不改原版**：`modules/` 脚本可能挂着定时任务，改参数 = 原项目按新参数跑 = 事故。
2. **上传云端前先问**：批量上传/建文档前，先讲清传多少、剩多少、传不上怎么办。
