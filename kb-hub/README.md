# 知识库体系门户（KB Hub）

**简体中文** ｜ [English](README.en.md)

把零散的**系统 / 模块 / 技能卡片 / 项目 / 资源 / 高频工具**统一聚合到一个本地仪表盘，
并提供**每日热度启动台**：点用即记录，按「使用频率 × 时间衰减」排序。

## 一句话启动

双击 `start-kbhub.bat` → 自动开浏览器 `http://127.0.0.1:8799/`。

或手动：

```bash
python kb_hub_server.py --kb-root "<你的知识库路径>" --port 8799
# 要求 Python 3.10+，仅用标准库
```

端口被占时自动顺延（8799 → 8808），不会静默失败。

> 卡片数量取决于**你自己的库**——首次运行看到的是示例清单，页面顶部会有提示条。

## 🔍 全库检索（三链路 RAG）

「🔍 全库检索」页签调用 `/api/rag`，由知识库侧的 `kb_rag.py` 执行：

- **链路 B 关键词**：SQLite FTS5 + jieba 分词（整篇 + 分块两个粒度 RRF 融合）——字词级精确
- **链路 C 语义向量**：BGE-small-zh 编码全部 chunk——换个说法也能搜到
- **保底 字级**：≥3 字走 FTS5 trigram、1-2 字走 LIKE（带超时熔断）——**一个字、一句话都搜得到**
- **「问知识库」**：把 top-k 命中组装成带编号引用的上下文包（markdown），可直接喂给 AI；零命中会明确说「库内未检索到相关内容」，不编

配置方式（二选一，**配置只在本机生效，不要提交**）：

1. 门户目录放 `rag.json`：
   ```json
   {"python": "<装有 jieba/numpy/torch 的解释器路径>", "script": "<kb_rag.py 路径>"}
   ```
2. 或设环境变量 `KB_RAG_PYTHON` / `KB_RAG_SCRIPT`。

未配置时接口返回明确提示，页面照常可用（其余页签不受影响）。

> 检索库（`kb.db`）是**本地派生层**：含 `raw/` 全文（含隐私目录正文），可删可重建，**严禁外传/上传/入 git**。

## 数据从哪来

```
inventory_builder.py  ──扫描──▶  inventory.json  ──读──▶  kb_hub_server.py  ──▶  web/index.html
   （你的库）                    （真实清单）              （本机 HTTP 服务）      （单文件前端）

usage.json  ◀── 每次点「打开 / 记一次」写时间戳 ──▶ 热度算法（频率 × 30 天线性衰减）
```

- `inventory.json`：**本机绝对路径 + 真实模块名，绝不入库**（`.gitignore` 已排除）；
- `inventory.example.json`：仓库自带的**纯虚构示例**，路径统一 `~/my-knowledge-base`，`exists` 全为 `false`；
- 缺失真实清单时自动回退示例，并在页面顶部提示「当前是示例清单」。

生成你自己的清单：

```bash
python inventory_builder.py --kb-root "你的知识库路径"
```

## 设计取舍

- **零依赖**：仅用 Python 标准库（`http.server`），不污染任何 venv，方便随知识库一起迁移、也方便打包成单文件 exe。
- **打开动作在本机执行**：门户用 `os.startfile` 直接打开目录/文件/启动子服务，所以**只绑 `127.0.0.1`**，不暴露到局域网。
- **路径用 `data-*` 传，不拼 `onclick` 字符串**：Windows 反斜杠会被 JS 当转义吃掉（`\Z` `\知`），
  这是本项目踩过的最大的一个坑——所有按钮曾经 100% 失效，页面看起来正常但点了没反应。
- **热度 = 频率 × 衰减**：避免「半年前用过一次」一直霸榜。
- **端口顺延 + 独立进程**：8787 子服务用 detached 进程启动，不随会话被回收。

## 文件

| 文件 | 作用 |
|---|---|
| `inventory_builder.py` | 扫描知识库 → `inventory.json` + 梳理报告 |
| `kb_hub_server.py` | 后端（标准库 HTTP，API 见文件头注释） |
| `web/index.html` | 前端仪表盘（单文件，原生 JS，零外链） |
| `start-kbhub.bat` | Windows 启动器（自动找 Python、自动顺延端口） |
| `inventory.example.json` | 示例清单（虚构） |
| `inventory.json` | 你的真实清单（运行后生成，**不入 git**） |
| `usage.json` | 热度数据（运行后生成，不入 git） |
| `rag.json` | 本地检索配置（解释器 + kb_rag.py 路径，**不入 git**） |

## 自检

页面加载时加 `?selftest=1`，会输出一段 JSON 到 `<pre id="selftest">`，逐页签报告
`hasAct / active / shown`，用于确认「导航真的能点」——这个自检是因为曾经踩过一次全站点不动的坑。
