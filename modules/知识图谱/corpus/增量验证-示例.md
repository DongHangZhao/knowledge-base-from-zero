# 增量插入验证文档

本文件只用于验证 W6 卡 B5：新增文档能否 `insert` 进已有图，而不重建全图。
内容是通用检索技术描述，不含任何真实业务数据。

检索层依赖分块与倒排索引，FTS5 用于字级召回，BGE 用于向量召回。
精排依赖 rerank 模型，RRF 用于把两路召回结果融合成统一排序。
PPR 依赖实体共现图，图检索用 PPR 扩散替代 1-hop 邻居扩展。

智能体工作流用于编排上述步骤，提示词定义每一步的输入输出。
双链路体系把字级召回与向量召回并行执行，再用 RRF 融合，最后交给精排。
评测依赖 golden set 与配对检验，判定规则必须提前写死，不许事后改判据。
