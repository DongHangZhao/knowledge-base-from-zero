# Prompt asset · copy, never modify the original (example card)

[简体中文](复用副本不改原版.example.md) ｜ **English**

> Every markdown file under `wiki/prompt-assets/` is the source of one reusable prompt card.
> Rerunning `scan_skills.py` adds it to the skill workbench automatically.

## When to use
A new task arrives and `wiki/reusable-modules/overview.md` already lists a capability that fits.

## Ready-to-use phrasing
```
Copy the whole modules/<original-domain>/ directory to modules/<new-domain>/,
rename the script, change only the parameter block (paths / keywords / state / cloud folder IDs).
Do not touch the main flow, the state mechanism, resumable downloads or the circuit breaker.
```

## Worked example
- Original: a WeChat sync that runs daily at 10:00. Copied into a "DingTalk sync" by changing only the source directory and destination folder.

## Bilingual term note
- 复用 = reuse; 副本 = copy; 原版 = original (do not modify)

## Trigger words
reuse / copy the directory / don't touch the original / check for wheels first
