# 提示词资产 · 复用副本不改原版（示例卡片）

**简体中文** ｜ [English](复用副本不改原版.example.en.md)

> `wiki/提示词资产/` 下每张 md 都是一张「可复用提示词卡片」的源。
> 重跑 `scan_skills.py` 后会自动进技能工作台。

## 适用场景
接到新任务、发现 `wiki/可复用模块/总览.md` 里有现成能力时。

## 即用话术
```
把 modules/<原领域>/ 整个目录复制到 modules/<新领域>/，
脚本改名，只改参数区（路径/关键词/state/云端文件夹 ID），
主流程、state 机制、断点续传、熔断 —— 别动。
```

## 落地例子
- 原：微信同步每天 10:00 自动跑；复制成「钉钉同步」只改源目录与目标文件夹。

## 例子中英对照
- 复用 = reuse；副本 = copy；原版 = original（do not modify）

## 触发词
复用 / 复制副本 / 别改原版 / 新任务先查轮子
