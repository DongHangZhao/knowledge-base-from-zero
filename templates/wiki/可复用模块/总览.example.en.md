## Two red lines
1. **Reuse = copy the directory, never modify the original**: scripts may be wired to scheduled jobs — changing parameters means the original project starts running with your values. That is an incident.
2. **Ask before uploading to the cloud**: how much, how much room is left, what happens if it fails.

## Principles
1. Look before you write; 2. Copy, don't modify the original; 3. Ask before uploading; 4. Push shared logic down; 5. One README per module; 6. Update the docs when you change the code.
